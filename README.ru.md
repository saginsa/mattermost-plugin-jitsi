# Плагин Jitsi для Mattermost — форк со звонком

Форк [официального плагина](https://github.com/mattermost-community/mattermost-plugin-jitsi) с двумя доработками. Готовые сборки — на странице [Releases](../../releases).

## Звонок, когда кто-то начинает встречу

| Где началась встреча | Что слышно |
|---|---|
| Личка, группа | Рингтон каждые 3 с — пока не нажмёшь «Подключиться» или не пройдёт заданное время (по умолчанию 60 с). Открыть разговор и читать переписку можно — звонок не прервётся |
| Канал | Один короткий сигнал |

Тишина, если встречу начал ты сам, у тебя статус «Не беспокоить» / «Нет на месте» или канал заглушён.
Звук синтезируется через WebAudio, звуковых файлов нет. Работает в десктопе и браузере (в браузере — после первого клика по странице: политика автовоспроизведения). Мобильные приложения клиентский код плагинов не выполняют.

- Администратор: **Системная консоль → Plugins → Jitsi**:
  - **Ring when a meeting starts** — включить/выключить (по умолчанию включено);
  - **Ring duration (seconds)** — сколько звонить, 5–600 с (по умолчанию 60);
  - **Users who never ring** — логины через запятую или пробел, у которых звонка и сигнала нет совсем: например, учётки переговорных ВКС, куда ссылки отправляют заранее. Остальных участников это не касается, в том числе в группе с такой учёткой.
- Пользователь: `/jitsi settings ring true|false`.

## Ссылка встречи без имени

С 2.1.0 в ссылку поста о встрече дописывается `userInfo.displayName` с логином того, кто смотрит пост. Ссылку копируют и пересылают — и все заходят в Jitsi под именем скопировавшего. Теперь имя добавляется только при клике по ссылке.

## Установка

Системная консоль → Plugins → Plugin Management → Upload Plugin (или `mmctl plugin add jitsi-*.tar.gz`). Id плагина тот же — `jitsi`, сборка заменяет официальный плагин и сохраняет его настройки. Откат — загрузить официальный релиз. Проверить архив — по `SHA256SUMS` в релизе.

Сборки делает [GitHub Actions](.github/workflows/fork-release.yml) из публичного кода, версия — `<версия апстрима>+ring.<N>`. Обе доработки предложены в апстрим отдельными pull request'ами.
